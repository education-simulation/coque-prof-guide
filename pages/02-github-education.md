# 2. GitHub Education (facultatif)

Tu peux **passer cette étape** : tout le parcours marche avec un compte gratuit ordinaire.

GitHub Education donne aux enseignants vérifiés quelques avantages, dont la possibilité de créer une **organisation** (par exemple pour ton établissement ou ton association) en formule **GitHub Team gratuite**.

## Faire la demande

1. Va sur **[github.com/education](https://github.com/education?locale=fr-FR)** et choisis **enseignant (Faculty)**.
2. Utilise ton **adresse académique** (`@ac-….fr`).
3. Joins un **justificatif daté** de ton poste (attestation d'exercice, bulletin de salaire en masquant les montants…).
4. La validation peut prendre **de quelques heures à deux semaines**. **N'attends pas** pour continuer le guide.

## Ce que ça change pour ton site

- Ton site doit être **public** pour être en ligne gratuitement.
- Avec une **organisation** passée en GitHub Team grâce à Education, les **fichiers** de ton site peuvent rester privés… mais **le site publié reste visible par tous**. Dans le doute, garde tout en public : c'est le plus simple.

*Informations vérifiées le 10/11/2026 sur les pages officielles de GitHub ; elles peuvent changer.*
