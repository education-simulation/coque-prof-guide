# 5. Brancher Mistral

**Mistral Vibe** est ton assistant. Son panneau est **à droite** de l'atelier (icône « M » orange dans la barre de gauche s'il est fermé).

Il te faut un **compte Mistral** : [chat.mistral.ai](https://chat.mistral.ai). Crée-le de préférence avec ton **adresse académique** : l'offre gratuite suffit pour commencer, et l'adresse académique te donne accès à l'**offre Éducation à tarif réduit** si tu en as besoin plus tard (voir [Gratuit ? Jusqu'où ?](#/couts)).

> ⚡ **Fais les clics 1 à 4 d'une traite**, sans t'interrompre : la demande de connexion expire au bout de quelques minutes.

## 1. Continuer avec Mistral AI

Dans le panneau Mistral, clique sur **Continuer avec Mistral AI**.

![Le panneau Mistral : bouton vert « Continuer avec Mistral AI »](captures/12-2-panneau-mistral.png)

## 2. Ouvrir

Une fenêtre demande **« Voulez-vous que Code ouvre le site web externe ? »** : clique sur **Ouvrir**.

![La fenêtre « ouvrir le site web externe » : bouton vert « Ouvrir »](captures/13-1-mistral-connexion-ouvrir-site-externe.png)

## 3. Autoriser

Un **nouvel onglet** s'ouvre : connecte-toi à ton compte Mistral, puis, sur l'écran **« Autoriser Mistral Vibe Code ? »**, clique sur **Autoriser**.

![En bas de l'écran Mistral : bouton « Autoriser »](captures/13-2-autoriser-boutons.png)

## 4. Revenir dans l'atelier

**Reviens sur l'onglet « RASF — Atelier … »**. Le panneau Mistral affiche **« Quelle est la mission ? »** : tu es connecté.

## 5. Faire confiance au dossier

En bas du panneau Mistral, clique sur **Dossier non approuvé**, puis sur le bouton vert **Faire confiance au dossier**.

![La fenêtre Mistral : bouton vert « Faire confiance au dossier »](captures/13-6-mistral-faire-confiance-au-dossier-propre.png)
