# 3. Copier le modèle

Le RASF te prête un **modèle** de site déjà prêt. Tu en fais **ta copie**, qui t'appartient.

1. Connecte-toi à GitHub, puis ouvre le modèle : **[le modèle « Atelier RASF » (niveau 1)](https://github.com/education-simulation/coque-prof-pages)**.
2. Clique sur le bouton vert **Use this template**, puis **Create a new repository**.

![La page du modèle, avec le bouton vert « Use this template »](captures/04-1-page-du-modele.jpg)

3. Donne un **nom** à ta copie (par exemple `mon-site-chimie`) : il apparaîtra dans l'adresse de ton site.
4. **Laisse « Public » coché** : c'est obligatoire pour que ton site soit en ligne gratuitement.
5. Clique sur **Create repository**.

![Le formulaire : nom du dépôt, et la visibilité « Public » déjà choisie](captures/04-2-creer-depuis-modele.jpg)

Tu arrives sur **ta copie**. Elle n'a plus de bouton « Use this template » : c'est le signe que tu es bien chez toi.
