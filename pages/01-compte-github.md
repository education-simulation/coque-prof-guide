# 1. Ton compte GitHub

**GitHub** est le site qui va garder les fichiers de ton site de cours et le mettre en ligne. C'est gratuit.

## Créer le compte

1. Va sur **[github.com/signup](https://github.com/signup)**.
2. Entre ton adresse mail, choisis un mot de passe, puis un **pseudo** : il apparaîtra dans l'adresse de ton site (`https://ton-pseudo.github.io/…`). Choisis-le court et sérieux.
3. GitHub t'envoie un **code par mail** : recopie-le.
4. Réponds aux quelques questions de bienvenue (tu peux passer).

## Installer l'application GitHub Mobile (important)

Pour certaines actions (rendre un dépôt public, changer un réglage), GitHub vérifie que c'est bien toi : il affiche **un code à deux chiffres** sur ton écran, et tu dois **toucher le même code sur ton téléphone**, dans l'application **GitHub Mobile**.

1. Installe **GitHub Mobile** (App Store ou Google Play).
2. Connecte-toi avec ton nouveau compte.
3. GitHub te proposera d'activer la **double authentification** : accepte, et choisis l'application GitHub Mobile.

> 🔐 **C'est toi seul qui crées ton compte et tes mots de passe.** Personne (ni Mistral, ni le RASF) ne doit jamais te les demander.
