# 7. Mettre en ligne

Mistral enregistre tes changements sur GitHub. Pour que ton site soit **visible par tous**, il reste **un réglage à faire une seule fois**, sur GitHub (Mistral ne peut pas le faire à ta place). Il te guidera, avec les liens complets.

## Le réglage

1. Dans l'onglet de **ton dépôt sur GitHub** (pas l'atelier) : **Settings** (l'engrenage, en haut).
2. Dans la colonne de gauche : **Pages**.
3. Sous « Build and deployment », menu **Source** : choisis **GitHub Actions**.
4. **Ne clique sur aucun bouton « Configure »** : ton site a déjà sa recette de mise en ligne.

![Settings → Pages → Source : « GitHub Actions ». Ne pas cliquer sur « Configure ».](captures/17-1-pages-source-github-actions.webp)

GitHub peut te demander de **confirmer avec ton téléphone** (application GitHub Mobile, code à deux chiffres) : c'est normal.

## ⏳ Patiente une minute

Dis à Mistral **« c'est fait »** : il relance la mise en ligne. Dans l'onglet **Actions** de ton dépôt, la ligne « Mise en ligne » affiche d'abord **un rond orange qui tourne** : attends environ **une minute**, jusqu'à la **coche verte**.

## Ton site est en ligne 🎉

Son adresse : **`https://ton-pseudo.github.io/nom-de-ta-copie/`** — Mistral te la donne en entier. Essaie-la aussi sur ton téléphone, et envoie-la à tes élèves.

Exemple : **[education-simulation.github.io/mon-site-test](https://education-simulation.github.io/mon-site-test/)**

Ensuite, demande à Mistral d'**ajouter ta première vraie page** : un cours, un exercice, une simulation.
