# Atelier RASF — le site-guide

Le pas-à-pas illustré, pour les enseignants, du compte GitHub jusqu'à leur site de cours en ligne (modèle niveau 1, assistant Mistral).

- Le menu se règle dans `site.config.js`, les pages sont dans `pages/`, les captures dans `captures/`.
- **Toutes les captures sont relues avant publication** : aucune adresse mail, aucun nom, aucune donnée personnelle.
- Mise en ligne : GitHub Pages (Settings → Pages → Source : GitHub Actions).
